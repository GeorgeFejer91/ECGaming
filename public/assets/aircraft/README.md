# Aircraft asset manifest

These GLBs are redistributable runtime conversions of the sources credited in
the repository root `THIRD_PARTY_NOTICES.md`. The originals are not claimed as
ECGaming work.

| --- | --- | --- |

| `og-biplane.glb` | mfep, *Low-Poly Biplane* | CC0 1.0 |
| `styloo-*.glb` (15 variants) | styloo, *Tiny Plane Asset Pack* | CC0 1.0 |
| `poly-cute-airplane.glb` | Akash Rudra, *very cute airplane* | CC BY 3.0 |

| `magic-low-poly-airplane.glb` | Magic Games, *Low Poly Airplane* | CC BY 4.0 |

The files were converted to embedded GLB for browser delivery. At runtime,
ECGaming centers, orients, and uniformly scales each model to the ring-safe
flight envelope. A separately authored ECGaming propeller is attached and
animated for every catalog choice; no source-authored animation is implied.

Complete Creative Commons legal-code copies are in `licenses/`. The Magic Games
archive's own license notice is retained there as
`MagicGames-source-license.txt`.
