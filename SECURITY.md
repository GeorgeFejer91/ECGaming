# Security and privacy

The v1 VDO.Ninja room is intentionally public and unauthenticated. Source labels are random but are not credentials. Report vulnerabilities privately through GitHub Security Advisories rather than opening a public issue with exploit details.

Never submit participant physiology, exported session CSVs, raw ECG, device identifiers, room traces, or other personal data in an issue. EC Gaming has no backend and should not make background uploads.
