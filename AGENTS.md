# ECGaming agent instructions

Read [for-ai/README.md](for-ai/README.md) at project entry, then resume the
goal and active checklist in [for-ai/PROJECT.md](for-ai/PROJECT.md). Load only
the task's selected guidance and skill bodies.

## Publish website changes promptly

For user-authorized website changes, do not leave completed work only in the
local worktree. As soon as the scoped checks pass:

1. create a focused commit containing only the intended, validated changes;
2. push the current tracked branch promptly so the website deployment can
   begin; and
3. verify the remote branch revision and deployment workflow when available.

Never force-push. Never include unrelated or unvalidated worktree changes just
to publish quickly. If overlapping local work prevents a safe focused commit,
report that blocker immediately.

## Shared project workflow

[for-ai/SKILLS.md](for-ai/SKILLS.md) routes RTK output guidance, GSD lifecycle
discipline, focused Superpowers practices, and the applicable interface skills.
For text-bearing HTML/CSS work, use `uncodixfy-pretext`, `ponytail`, and the
accessibility route. Preserve the current stack and product contracts.

Keep one plan and checklist owner. Before ending, update that state with
evidence, blockers, the next action, and observed Git/publication state. Keep
the overall goal open until its own acceptance criteria pass. Skill routes do
not independently authorize delegation, dependencies, or publication.
